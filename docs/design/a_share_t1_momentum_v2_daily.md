# A 股 T+1 日线动量策略 v0.2（Daily-Only）

> 来源：Martin Luke 2025 美股投资冠军赛思维导图。
> 本版**只使用日线 OHLCV**，不依赖分钟线、集合竞价、盘口封单。
> 状态：**方案，未回测**。所有收益数字均为待验证假设。

## 0. 一页纸结论

**一句话**：在指数/宽度/情绪转暖的日子，从“主板 + 创业板、趋势向上、相对强度前 20%、板块主线”的股票里，等日线回踩 21EMA/AVWAP 缩量止跌，或收盘放量突破 10–20 日平台；**T 日收盘确认，T+1 开盘买入**；用 2%–5% 的结构止损换 2R–3.5R，单笔风险预算 0.3%–0.5%，收盘触发、次日开盘执行。

**与 v0.1 的区别**：

| v0.1 | v0.2（只有日线） |
|---|---|
| 14:30 盘中买入 | **T 日收盘确认，T+1 开盘买** |
| 5/15 分钟确认 | 只用日线 K 线/量能 |
| 盘前竞价扫描 | 用前一日收盘 + T+1 开盘跳空过滤 |
| T+1 起日内条件单 | **只做收盘止损、次日开盘卖** |
| 涨停封单 > 流通 1% | 删除；用成交量/收盘行为代理 |
| 事件跳空 10% 追入 | 跳空后等 2–10 日回踩确认 |

**设计目标（待验证）**：年化 **8%–15%**、最大回撤 **15%–20%**、Sharpe 0.6–1.0、年交易 100–160 笔。  
比 v0.1 更保守：日线版没有日内止损，左尾更胖，不能按原策略的 10%–20% 年化承诺。

**核心风险**：T+1 下唯一能执行的止损是“收盘跌破 → 次日开盘卖”；隔夜跳空可能把 1R 打成 1.6R–3R。所有参数和仓位必须围绕这一点设计。

## 2. T+1 执行模型（先定死，不能再有第二套）

### 2.1 时间轴

```
T 日 15:00 收盘
  → 用 T 日收盘数据生成信号
T+1 09:30 开盘
  → 按开盘价 + 跳空过滤买入
T+1 收盘
  → 买入当日不能卖；只记录收盘是否跌破止损
T+2 起
  → 每日收盘检查止损/目标；收盘触发，下一交易日开盘执行
```

- **买入当日（T+1）绝对不卖**；
- **止损**：T+1 收盘 < S0 → T+2 开盘卖；若 T+2 跌停/停牌，顺延；
- **目标**：T+1 起可挂限价卖单；日线回测按“开盘 ≥ 目标 → 开盘价成交；否则 high ≥ 目标 → 目标价成交”；
- **同一日 high 触目标、low 触止损**：日线无法知道先后，**保守版按止损先执行**，并在报告标注“日线顺序不确定”。

### 2.2 两个 R

```
价格 R = 入场价 P − 结构止损 S0
账户 1R = 仓位金额 × 价格 R / P = w × d
```

- 交易卡写价格 R；
- 绩效、期望、回撤统一用账户 R；
- 不允许把价格 R 当收益、账户 R 当风险混用。

### 2.3 有效止损与仓位

```
d = clamp(0.5 × ADR20, 2%, 5%)
g = clamp(0.5 × ADR20, 1.5%, 3.5%)     # 跳空缓冲
D_eff = d + g
r_budget = 0.5% / 0.4% / 0.3%          # 进攻/中性/防守
w = min(r_budget / D_eff, w_max)
shares = floor(equity × w / P / 100) × 100
```

**算例**：100 万、P=20、d=2.5%、g=2.5%、r=0.5%：

| 项 | 值 |
|---|---:|
| D_eff | 5% |
| w | 10% |
| 买入金额 | 10 万 |
| 正常止损亏损 | 2,500 元（账户 0.25%，1R） |
| 跳空最坏亏损 | 5,000 元（账户 0.50%，预算上限） |

> 注意：r_budget=0.5% 是**最坏亏损预算**，不是 1R；1R 只有 0.25%。报告必须写清。

### 3.1 指标

## 4. 第 1 层：日线股票池

### 4.1 硬过滤

| 维度 | 规则 |
|---|---|
| 板块 | 沪深主板（60/00）+ 创业板（300/301）；**排除科创板 688、北交所 920/8** |
| ST | 排除 ST/*ST/退市整理 |
| 上市 | >120 个交易日 |
| 流通市值 | 30 亿–800 亿 |
| 20 日均成交额 | >2 亿 |
| 20 日均换手 | 2%–25% |
| 价格 | >3 元 |
| 位置 | 距 250 日高点 <30% |
| 风险事件 | 排除近 30 日解禁/减持/问询/预亏（数据可用时） |

- **PIT**：用当日可得的 ST/上市/退市/停牌状态，不能用当前成分回看；
- 已退市股票保留在历史池中；
- 北交所排除，避免 30% 涨跌幅和 920 编码回溯问题。

### 4.2 相对强度

- 20 日涨幅在全池百分位 >80%；
- RS 线（个股/中证 1000）在 20 日新高附近，或站上 20 日均线；
- 60 日新高优先，其次 20 日新高。

### 4.3 板块/主线

- 概念板块 5 日、20 日涨幅排名前 10%；
- 板块内涨停 ≥3，或板块涨幅 >2% 且成交额放大；
- 只做前 3 条主线；
- 板块内选最强：涨幅/成交额/最先涨停/连板最高；
- 板块高潮次日不追；
- 概念成分必须 PIT；没有 PIT 先用行业，报告标注。

## 5. 第 2 层：三种日线形态

### 5.1 形态 A：回调买入（主力，50% 仓位）

| 条件 | 日线规则 |
|---|---|
| 前置 | 20 日内创 60 日新高，或突破平台 ≥5% |
| 回调 | 3–8 个交易日，回撤 ≤1.5×ADR20 |
| 支撑 | 收盘在 EMA21 ±2%，或 AVWAP ±2%，或前高/缺口上沿 |
| 量能 | 回调期均量 <突破日 60%，且 <20 日均量 80% |
| 止跌 K | 阳包阴 / 锤子 / 十字星 / inside day，至少一种 |
| 止损 | `min(回调低点, EMA21) − 0.3×ADR`；d 必须在 2%–5% |
| 目标 | 前高 +1×ADR；2R / 3.5R 分批 |

### 5.2 形态 B：突破买入（30%）

| 条件 | 日线规则 |
|---|---|
| 平台 | 10–20 日，振幅 <10% |
| 量能 | 平台期 20 日均量 <前 20 日的 80% |
| 位置 | 收盘在 EMA21 上方，距平台高 <5% |
| 突破 | 收盘 >平台高 ×1.005，量 >1.5×20 日均量 |
| 幅度 | 当日涨幅 3%–7%；**不买涨停** |
| 止损 | 平台高 ×0.97，或突破日低点 −0.3×ADR |
| 目标 | 平台高度投射，或 2R / 3.5R |

### 5.3 形态 C：事件/跳空（20%）

| 条件 | 日线规则 |
|---|---|
| 事件 | 业绩超预期、政策、订单、并购 |
| 跳空 | ≥5%，当日成交额 >2×20 日均额 |
| 不追 | 当日不买，等 2–10 日 |
| 回踩 | 缺口上沿 / EMA9 / EMA21，缩量，止跌 K |
| 止损 | 缺口下沿，或回踩低点 −0.3×ADR |
| 排除 | 跳空 >15%、当日高开低走 >5%、利好已兑现 |

### 5.4 优先级

```
回调 > 突破 > 事件
```

日线版里回调止损最近、隔夜不确定性最小；事件型只做确认后的第二波。

## 6. 第 3 层：T+1 开盘入场

### 6.1 时点

| 形态 | 信号 | 执行 |
|---|---|---|
| 回调 | T 日收盘确认止跌 | T+1 开盘 |
| 突破 | T 日收盘确认突破 | T+1 开盘 |
| 事件 | T 日收盘确认回踩 | T+1 开盘 |

**没有 14:30 入场**；所有信号用 T 日收盘数据，T+1 开盘执行。

### 6.2 跳空过滤（T+1 开盘）

| 开盘相对前收 | 动作 |
|---|---|
| >+5% | 不追，等回踩 5 日均线 |
| +2%–+5% | 可买，仓位 ×0.7 |
| -3%–+2% | 正常 |
| <-3% | 放弃，形态破坏 |
| 一字涨停 / 开盘涨停 | 放弃 |
| 跌停开盘 | 不买 |

### 6.3 不买清单

- 当日涨幅 >7%（T+1 无保护）；
- 连续涨停 ≥3 板；
- 巨量长上影 / 天量滞涨；
- 板块高潮次日；
- 财报前 3 日（除非事件型已确认）；
- 防守档。

## 7. 第 4 层：日线止损

### 7.1 只保留可执行的五类

| 类型 | 触发 | 执行 |
|---|---|---|
| 结构止损 | 收盘 <S0 | 次日开盘卖 |
| 硬止损 | 收盘 <入场×(1−6%) 主板 / (1−8%) 创业板，或亏损 ≥2.5R | 次日开盘无条件卖 |
| 时间止损 1 | 5 日未达 +1R | 次日开盘减半 |
| 时间止损 2 | 10 日未达 +1.5R | 次日开盘清仓 |
| 移动止损 | +2R→成本；+3R→+1R；之后收盘 <10EMA/21EMA | 次日开盘卖 |
| 大盘止损 | 指数 <EMA21 且跌停 >30 | 次日全部减半 |

### 7.2 成交规则

- 收盘触发，**次日开盘卖**；
- 次日开盘 ≤跌停价：不成交，顺延到打开跌停；
- 停牌：顺延；
- 同一日 high 触目标、low 触止损：**保守版按止损先执行**；
- 不允许“收盘价一定能卖”。

### 7.3 止损宽度

```
d = clamp(0.5×ADR20, 2%, 5%)
```

- d<1.5%：太紧，放弃；
- d>5%：太宽，盈亏比不划算，放弃；
- 结构位与 0.5×ADR 冲突时取更近结构位，但不小于 1.5%。

## 8. 第 4 层：仓位

### 8.1 公式

```
r_budget = 0.5% / 0.4% / 0.3%
d = clamp(0.5×ADR20, 2%, 5%)
g = clamp(0.5×ADR20, 1.5%, 3.5%)
D_eff = d + g
w = min(r_budget / D_eff, w_max)
shares = floor(equity × w / P / 100) × 100
```

### 8.2 上限

| 约束 | 值 |
|---|---|
| 单票（主板） | 15% |
| 单票（创业板/流通<80 亿） | 10% |
| 同时持仓 | 4–8 只 |
| 单行业 | ≤2 只 |
| 单概念 | ≤3 只 |
| 小盘合计（<100 亿） | ≤60% |
| 总仓位 | 80/50/20/0（按 regime） |

### 8.3 加仓

- 只在浮盈 ≥+1R 后；
- 回踩 10EMA 不破，加原仓位 1/3；
- 加仓后总风险 ≤0.6%；
- 最多加一次，不摊平亏损。

### 8.4 连亏降档

| 连续止损 | r_budget |
|---|---|
| 0–2 | 正常 |
| 3 | ×0.75 |
| 4 | ×0.5 |
| 5 | 停手 2 日 |

## 9. 第 5 层：日线卖出

| 阶段 | 条件 | 动作 |
|---|---|---|
| 第一目标 | 收盘/开盘达 +2R | 卖 1/3 |
| 第二目标 | +3.5R | 再卖 1/3 |
| 移动 1 | 收盘 <10EMA | 卖剩余 1/2 |
| 移动 2 | 收盘 <21EMA | 清仓 |
| 放量滞涨 | 量 >2×20 日均量，涨幅 <2% 或上影 >2×实体 | 卖 1/2 |
| 大盘转弱 | 指数 <21EMA 且跌停 >30 | 全部减半 |
| 黑天鹅 | 跌停/停牌 | 排队；打开即卖 |

**日线目标成交假设**：

- T+1 起，开盘 ≥目标 → 开盘价成交；
- 否则 high ≥目标 → 目标价成交（限价单）；
- 买入当日不卖；
- 同一日目标/止损都触 → 保守版止损优先。

## 10. 回测规格

### 10.1 数据

| 数据 | 用途 | 现状 |
|---|---|---|
| 日线 OHLCV（前复权+原始价） | 信号+成交 | 已有 |
| 000852/000300/399006 | 环境 | 已有/待确认 |
| 概念/行业 PIT | 板块 | 部分 |
| ST 历史/停牌/退市 | 池 | 缺，Phase 0 补 |
| 涨跌停价 | 成交 | 可算 |
| 公告日 PIT | 事件 | 缺 |
| 5/15m | 不做 | 本版不需要 |

### 10.2 撮合

- T 日收盘信号，T+1 开盘入场；
- 涨停开盘不买；跌停开盘不卖；停牌顺延；
- 止损收盘触发、次日开盘；
- 目标限价单；
- T+1 买入当日禁卖；
- 费用：佣金 0.025%（最低 5）+ 印花税 **2023-08-28 前 0.1%、之后 0.05%** + 过户费 0.001% + 滑点 0.1%–0.2%。

### 10.3 指标

- 收益：年化、累计、超额（000852）；
- 风险：MaxDD、回撤持续期、下行波动、VaR/CVaR；
- 交易：胜率、账户 R 期望、PF、最大单笔亏损、连续亏损、**跳空穿越止损比例**；
- 稳健：分 regime/市值/行业/形态；
- 容量：成交额占比、资金上限。

### 10.4 必做对照

- 随机入场；
- 纯 EMA21 趋势持有；
- 等权基准；
- 成本 2×；
- 止损从“收盘次日”改成“日内”只作为上界参考，不作为可实现收益。

## 11. 验证顺序与门槛

### Phase 1：只做回调型

- 2018–2025 日线；
- 收盘确认，T+1 开盘；
- 保守止损；
- 先不碰突破/事件。

**通过门槛**：

- 净期望 >0.2R；
- MaxDD <20%；
- 至少 2/3 的 regime 为正；
- 剔除最好 5% 交易仍为正；
- 成本 2× 仍为正。

不达标就停止，不加形态。

### Phase 2：突破 + 事件

- 分开跑，不混在一起；
- 每种形态独立归因；
- 事件型需要公告日 PIT，数据不够就砍掉。

### Phase 3：稳健性

- 参数 ±20%；
- 分年/分 regime；
- bootstrap 5% 分位回撤；
- 容量/滑点压力；
- 样本外。

## 13. 日线版已知局限

1. **没有日内止损**：买入当日只能看收盘，隔夜跳空把 1R 打大；
2. **没有集合竞价**：无法做盘前 gap/竞价量扫描，只能用开盘价过滤；
3. **没有分钟确认**：回调 V 反、突破开盘区间都降级为日线 K；
4. **没有封单数据**：涨停封单规则删除；
5. **事件形态依赖公告日 PIT**：没有就砍掉；
6. **概念成分 PIT 不完整**：先用行业，报告标注；
7. **7:1 不可复制**：2.5:1–3.5:1、35%–45% 胜率是另一套分布，必须重新验证；
8. **收益目标下调**：8%–15% 年化，不是 10%–20%。
