## 八、补齐对因子研究的影响（实测）

用**同一批 85 个价量因子**、同一评价口径（点位池 200、2019-01 ~ 2026-10、T+1 开盘、双边 20bp），
在补齐前后各跑一次评分卡，对比结果：

### 8.1 分类别 IC 变化

| 类别 | 因子数 | IC（补齐前） | IC（补齐后） | 变化 |
|---|---|---|---|---|
| **liquidity** | 35 | 0.0301 | **0.0227** | **-25%** |
| momentum | 20 | 0.0145 | 0.0137 | -5% |
| reversal | 3 | 0.0155 | 0.0154 | 0% |
| risk | 25 | 0.0178 | **0.0198** | **+11%** |
| size | 2 | — | — | 无市值列 |

- 全部因子平均 |ΔIC| = **0.0039**
- **49/85 因子 IC 下降**，36 个上升

### 8.2 结论

1. **流动性/换手类因子的 IC 被旧样本高估约 25%**
   2019-2021 只有 790 只（且是当年成交额前 800），这批股票换手率高、波动大，
   放大了换手类因子的截面区分度。补到 3,600~5,000 只后回落到真实水平。

2. **风险类因子反而变强**（+11%）
   低波动/beta 类因子在大样本下更稳定，说明它们不是靠小样本的极端值撑起来的。

3. **评级变化 4 个**：

| 因子 | 旧 | 新 | 原因 |
|---|---|---|---|
| `liquidity.turnover_std_bias_42_252` | C | **A** | 分年同号率否决解除（样本变大后年度 IC 更稳定） |
| `momentum.alpha_500d_csi300` | C | D | 长窗 alpha 在小样本里是噪声 |
| `momentum.alpha_528d_sh` | C | D | 同上 |
| `risk.beta_500d_csi300` | D | C | 大样本下 beta 分层更单调 |

### 9.2 校验

- `suspend_d`：随机 20 个交易日，逐日 DB 行数与 Tushare 当日返回完全一致；
- `forecast`：随机 10 个公告日，逐日 DB 行数与 API 完全一致；
- `stk_limit`：抽查 2017-06-05 / 2018-01-02，DB 3,247 / 3,466 行与 API 一致；
- `disclosure_date`：每个报告期 `count() == count_distinct(code)`，无重复预约；
- `new_share`：2017-01-01 ~ 2026-11-07 分页拉取 2,796 条，DB 2,796 条，代码集合完全一致。

### 9.3 口径与缺口

| 事项 | 说明 |
|---|---|
| `stock_basic_history` 只有一个快照 | Tushare `stock_basic` 只给当前名单；历史成员用 `list_date` / `delist_date` 推导，历史名称/ST 用 `namechange` |

| 窗口外不抓 | `stk_limit` / `suspend_d` 不抓 2017-01-03 之前；`forecast` 不扫描 2017-01-01 之前 |
| 权限 | 2120 积分下 8 个接口全部可调用；`probe-p0` 可随时复检 |
