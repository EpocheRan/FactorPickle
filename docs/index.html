WHY FACTORPICKLE

为什么是 Factor Pickle

不是让 Agent 批量生成表达式，而是让一支有记忆、有验证、有审计的研究团队自主推进 campaign：会提出假设，也会承认失败、拒绝重复。

ROTATION000°
01 / AUTONOMOUS MINING

把因子研究变成自动 campaign

Agent 自主提出假设、组队执行、冻结预注册并跑 deterministic 评估；不是一次性批量生成表达式。

02 / FULL AGENT TEAM

五个角色，各自独立

PathFinder、Web Gateway、ML Planner、FactorBuilder、Reader 各有 campaign-scoped 任务与输出，不能共享、不能复用。

03 / VALIDATION

Gate pass 不是 promotion

long-only Gate + coverage + program FDR + 独立窗口 + 容量检查；任何一项不过都不算 validated。

04 / RESEARCH MEMORY

有记忆，不走回头路

结构化 prior results、hard negatives、source hashes 与 data provenance；LLM 只压缩叙述，不改事实。

05 / A-SHARE BACKTEST

A 股规则内置

T+1、整手、涨跌停、停牌、佣金与印花税；单标的与横截面共用一套账本。

06 / REPRODUCIBLE

可复现的运行

run_id 固化策略、参数、数据快照与执行规则；同输入可重跑，结论可对照。

07 / DATA BOUNDARY

单一数据边界

所有行情、财务、因子与持仓读写只经过 data_interface；Runner 不直连数据库。

08 / MCP NATIVE

MCP 原生

行情、财务、因子、选股、持仓与同步统一暴露为工具；研究结论仍由 deterministic Gate 裁决。

02B / BEYOND HUMAN

为什么这是“自动挖掘”，不是“批量跑因子”

真正的自动化不是把表达式生成得更多，而是让研究过程具备人类团队的经验积累、否定能力和审计边界。

BEYOND BATCH
MEMORY

不重复失败

validation hard negatives 与 exact-duplicate expressions 进入下一轮 context；PathFinder 必须承认或解释差异，不能重新发明同一条死路。

PROVENANCE

数据可追溯

context source hash 绑定 result、data_manifest、factor code、pre-registration 与 evaluation window；数据变了，记忆不会假装没变。

ADVERSARIAL

会拒绝自己

Gate/FDR/独立窗口/容量是确定性服务；LLM 不能把 fail 改成 pass，也不能用漂亮叙事覆盖容量未验证。

COMPRESSION

长链不丢重点

历史过长时用 DeepSeek Flash 压缩叙述，但 source ids、结构化 prior results 和 hard negatives 始终保留为事实层。

AUDIT

每轮可复核

fresh team tasks、campaign-scoped outputs、frozen pre-registration 与 memory audit 共同防止“同一个决策贴十次标签”。

STOP

知道何时停

campaign 有轮次/预算/重复停止；主线没有通过验证，就不开下一轮，而不是用更多参数掩盖失败。

03 / DSH RELATION

研究记忆跨会话延续

Factor Lab 跑在 DSH 工作区里：DSH 负责会话、Agent 与工具接入；Factor Lab 负责研究契约、artifact、validation ledger 与长期记忆。新会话不需要旧聊天记录，只需要同一份 context。

  • research_context.v2 携带 parent campaign、source hashes、hard negatives 与 data provenance；PathFinder 先读记忆再决策。
  • validation_results.jsonl 是 append-only 证据层：independent / FDR / top-N / capacity 状态不会被叙事覆盖。
  • DeepSeek Flash 只在历史过长时压缩叙述；结构化事实与 source ids 始终保留。
  • campaign、report、memory 全部落在 output/factor_lab，换会话仍可复核。

03 / MODES

执行模式，可扩展

ATR / GRID 只是内置实现。仓位管理与风控是开放接口，用户可以继续接入自己的模式。
